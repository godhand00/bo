# スパッタ成膜条件のベイズ最適化

RF スパッタリングによる SiO₂ 薄膜の成膜条件を、ベイズ最適化で探索するサンプルプログラムです。

---

## 背景知識：スパッタ成膜とは

### スパッタリングの原理

**スパッタリング**は、薄膜（数 nm ～ 数 μm の厚さ）を基板上に作る手法の一つです。

イメージとしては、「砂山にボールを投げつけると砂粒が飛び散る」のと似ています。

1. 真空チャンバー内にアルゴン（Ar）ガスを導入する
2. 高周波電圧（RF）をかけてアルゴンをプラズマ化（イオン化）する
3. Ar⁺ イオンが **ターゲット**（膜の材料となる板）に衝突する
4. ターゲットの原子がはじき出され（= スパッタされ）、対面に置かれた **基板** の上に堆積する
5. 堆積が進むと **薄膜** が形成される

```
   ┌───────────────────────────┐
   │        真空チャンバー       │
   │                           │
   │   ┌─────────────────┐     │
   │   │  ターゲット (SiO₂) │ ← Ar⁺ イオンが衝突      RF電源 ⚡
   │   └─────────────────┘     │
   │       ↓ ↓ ↓ ↓ ↓          │
   │     原子が飛び出す         │
   │       ↓ ↓ ↓ ↓ ↓          │
   │   ┌─────────────────┐     │
   │   │   基板（ウェハー）  │ ← ここに薄膜ができる     ヒーター 🔥
   │   └─────────────────┘     │
   │                           │
   │   ～～ Ar ガス ～～       │
   └───────────────────────────┘
```

### このサンプルで扱う材料

**SiO₂（二酸化ケイ素）** の薄膜を RF スパッタリングで成膜する想定です。SiO₂ は半導体デバイスの絶縁膜やレンズの反射防止膜など、幅広い用途で使われる代表的な薄膜材料です。

## 背景知識：成膜パラメータの意味

スパッタ成膜では、以下のパラメータを調整することで膜の性質が大きく変わります。

### RF出力（W：ワット）

ターゲットに衝突させるイオンのエネルギーを決める電力です。
- **大きくすると** → イオンが強くぶつかる → 多くの原子が飛び出す → **成膜が速くなる**
- **小さくすると** → 穏やかにスパッタされる → **膜が緻密になりにくい**

### Ar圧力（Pa：パスカル）

チャンバー内のアルゴンガスの圧力です。
- **高圧** → ガスが濃い → 飛んでいく原子が途中でガスにぶつかって散乱 → **成膜が遅くなり、膜が粗くなりやすい**
- **低圧** → 原子がまっすぐ基板に届く → **成膜レートが高く、緻密な膜になりやすい**

### 基板温度（°C）

基板を加熱する温度です。
- **高温** → 基板に到達した原子が表面を動き回れる → **結晶化が進み、緻密で平滑な膜**になる。膜の内部応力も緩和される
- **低温（室温付近）** → 原子があまり動けない → **密度が低く、表面が粗い膜**になりやすい

### Ar流量（sccm）

チャンバーに流し込むアルゴンガスの量です（sccm = standard cubic centimeter per minute）。
- 圧力の調整と連動しており、流量を変えるとプラズマの状態や成膜の安定性に影響します
- 本サンプルでは成膜レートに軽微な影響を与えるパラメータとして設定しています

### ターゲット-基板間距離（mm）

ターゲットと基板の間の物理的な距離です。
- **近い** → 飛び出した原子が短い距離で基板に到達 → **成膜レートが高い**が、膜厚の均一性が落ちやすい
- **遠い** → 散乱が増え成膜が遅くなるが、**膜厚が均一になりやすい**

## 背景知識：膜特性（最適化の目標値）

成膜された薄膜の「品質」を評価するために、以下の 4 つの特性を測定・最適化対象とします。

### 成膜レート（nm/min）

1分あたりに何 nm の厚さの膜ができるか。**大きいほどスループットが高く、製造コストが下がります。**

### 屈折率（@ 633nm）

光がその膜の中でどれだけ曲がるか（遅くなるか）を表す値。材料ごとに理想値（バルク値）があり、**SiO₂ のバルク値は約 1.46** です。この値に近いほど、膜が理想的な密度と組成を持っていることを意味します。値がずれていると、膜に空隙（ポーラス）があったり、組成がずれていたりすることを示唆します。

### 表面粗さ Ra（nm）

膜表面の凸凹の平均的な大きさ。**小さいほど滑らかで高品質な膜**です。光学部品では表面粗さが光の散乱に直結するため、特に重要です。

### 膜応力（MPa）

膜の中に蓄積された内部応力です。値が負なら**圧縮応力**（膜が縮もうとしている）、正なら**引張応力**（膜が伸びようとしている）を意味します。**絶対値が大きすぎると膜の剥がれやクラック**の原因になるため、なるべく小さい（＝ゼロに近い）ことが望ましいです。

## 背景知識：ベイズ最適化とは

### なぜ「ベイズ最適化」を使うのか？

成膜条件のパラメータ（5次元）の全ての組み合わせを試すのは現実的ではありません。たとえば各パラメータを10段階ずつ試すだけでも **10⁵ = 100,000 通り**になり、1回の実験に数時間かかる場合は到底不可能です。

ベイズ最適化は、**少ない実験回数で効率的に最適条件を見つける** ための手法です。

### 仕組みの概要

```
┌─────────────────────────────────────────────────┐
│                                                 │
│  ① これまでの実験データから                      │
│     「条件→結果」の予測モデルを作る               │
│     （ガウス過程回帰）                           │
│              ↓                                  │
│  ② まだ試していない条件の中から                   │
│     「最も試す価値がありそうな条件」を選ぶ         │
│     （獲得関数: EI, PI, LCB など）               │
│              ↓                                  │
│  ③ 選ばれた条件で実験（またはシミュレーション）    │
│              ↓                                  │
│  ④ 結果をデータに追加して ① に戻る               │
│                                                 │
└─────────────────────────────────────────────────┘
```

- **ガウス過程 (GP)**: 「この条件ならこのくらいの結果になりそう」という予測と、その**不確実性**を同時に推定してくれる統計モデルです
- **獲得関数**: 次にどの条件を試すかを決めるルール。「予測値が良さそうな場所を狙う」（活用）と「まだよくわからない場所を探る」（探索）のバランスを取ります

### グリッドサーチ・ランダムサーチとの違い

| 手法 | 特徴 | 必要な実験回数 |
|------|------|---------------|
| **グリッドサーチ** | 等間隔に全組み合わせを試す | 非常に多い |
| **ランダムサーチ** | ランダムにサンプリング | 多い |
| **ベイズ最適化** | 過去の結果から賢く次の点を選ぶ | **少ない** ✅ |

## 成膜パラメータ（探索空間）

| パラメータ | 単位 | 範囲 | 説明 |
|-----------|------|------|------|
| RF出力 | W | 50 ~ 300 | スパッタリングの投入電力 |
| Ar圧力 | Pa | 0.1 ~ 2.0 | チャンバー内ガス圧力 |
| 基板温度 | °C | 25 ~ 400 | 基板加熱温度 |
| Ar流量 | sccm | 5 ~ 50 | アルゴンガス流量 |
| T-S間距離 | mm | 40 ~ 120 | ターゲット-基板間距離 |

## 最適化対象の膜特性

| 特性 | 単位 | 目標 |
|------|------|------|
| 成膜レート | nm/min | 最大化 |
| 屈折率 (@633nm) | - | 1.46 (SiO₂バルク値) に近づける |
| 表面粗さ Ra | nm | 最小化 |
| 膜応力 | MPa | 絶対値を最小化 |

## 使い方

### 1. データセットの生成

```bash
uv run python generate_dataset.py
```

`data/` ディレクトリに初期実験データと検証用データが生成されます。

### 2. ベイズ最適化の実行

**基本的な実行（ランダム探索から開始）:**

```bash
uv run python bayesian_optimization.py
```

**初期実験データを活用して最適化:**

```bash
uv run python bayesian_optimization.py --initial-data data/initial_experiments.csv --n-calls 50
```

**オプション一覧:**

```bash
uv run python bayesian_optimization.py --help
```

| オプション | デフォルト | 説明 |
|-----------|-----------|------|
| `--n-calls` | 50 | 総評価回数 |
| `--n-initial` | 10 | 初期ランダム探索の点数 |
| `--initial-data` | None | 初期実験データCSVのパス |
| `--acq-func` | EI | 獲得関数 (EI/PI/LCB/gp_hedge) |
| `--seed` | 42 | 乱数シード |
| `--output-dir` | results | 出力ディレクトリ |

## 目的関数について

4つの膜特性を重み付きスカラー値に統合しています:

```
score = - w_rate × rate_norm
        + w_roughness × roughness_norm
        + w_ri × |RI - 1.46|_norm
        + w_stress × |stress|_norm
```

各重みは `bayesian_optimization.py` 内の `WEIGHTS` 辞書で変更可能です。

## カスタマイズのヒント

- **膜材料の変更**: `generate_dataset.py` の `simulate_deposition()` を修正
- **探索空間の変更**: `bayesian_optimization.py` の `search_space` を修正
- **目的関数の重みの変更**: `WEIGHTS` 辞書を修正
- **獲得関数の比較**: `--acq-func` オプションで EI, PI, LCB, gp_hedge を切り替え
- **実際の実験データの利用**: CSVを `--initial-data` で指定（カラム名を合わせること）

## 獲得関数の選択ガイド

| 獲得関数 | 特徴 |
|---------|------|
| **EI** (Expected Improvement) | 探索と活用のバランスが良い。一般的に推奨 |
| **PI** (Probability of Improvement) | 活用（exploitation）寄り。局所的に探索 |
| **LCB** (Lower Confidence Bound) | κパラメータで探索/活用を制御可能 |
| **gp_hedge** | 複数の獲得関数を自動切り替え |
